description: The Mini Dreams GitHub repository contains the complete app history, while the original local workspace began as a starter scaffold.

For Mini Dreams changes, treat the GitHub `main` branch as the source of truth when the local starter history and the repository history diverge.

**Why:** The remote repository contains the finished Mini Dreams app and its deployment configuration; the original local branch was only the generic workspace scaffold.

**How to apply:** Compare histories before syncing, avoid blind merges or overwrites, and preserve a clean working tree before applying requested edits.
